## Message Upwork prêt à copier

Bonjour Antoine,

Voici mon intégration Maison Célestine, prête à être testée :

**Page produit :** https://maison-celestine-knr-test.myshopify.com/products/serum-precieux-regenerant  
**Mot de passe :** KNRDEV  
**Code et documentation :** https://github.com/dragnoir/knr-maison-celestine

J’ai porté une attention particulière à la fidélité desktop et mobile : comparaison section par section des espacements, typographies, couleurs, recadrages et textes, puis vérification sur sept largeurs, de 320 à 1920 px.

L’intégration repose sur Horizon, Shopify CLI, Liquid, CSS et JavaScript natif, sans framework ajouté. Elle comprend :

- un template produit Liquid dédié et douze sections aux réglages et blocs éditables ;
- deux variantes synchronisant prix, prix barré, prix unitaire, disponibilité, image et URL, y compris l’achat flottant ;
- un panier Ajax en superposition avec quantités, retrait et ajouts rapides des produits complémentaires sans quitter la fiche ;
- galerie tactile, avant/après, témoignages, FAQ, filtres d’avis et chargement supplémentaire ;
- les formulaires natifs Shopify pour newsletter, avis et questions, avec modération manuelle des avis de démonstration ;
- navigation clavier, cibles tactiles adaptées et animations discrètes, désactivables dans Shopify et respectant la réduction des mouvements.

Les produits, métachamps, métaobjets, menus et articles alimentent les contenus. Des modifications dans Shopify ont été testées puis restaurées pour vérifier l’édition sans retoucher le code. Les parcours variantes/panier ont également été vérifiés sur iPhone.

Les contrôles de code passent ; Theme Check ne relève aucune erreur, avec deux avertissements existants du thème de base. Images responsives, polices auto-hébergées et JavaScript différé limitent la charge. Les audits PageSpeed datés sont fournis : médianes 98 sur ordinateur et 81 sur mobile sur la prévisualisation protégée. La variabilité du LCP mobile et l’antériorité de ces mesures aux derniers ajustements sont explicitées dans le rapport.

Pour faciliter votre revue :

- **Parcours vidéo :** https://github.com/dragnoir/knr-maison-celestine/blob/main/docs/walkthrough/maison-celestine-parcours.mp4
- **Validation et preuves :** https://github.com/dragnoir/knr-maison-celestine/blob/main/docs/VALIDATION.md
- **Choix et corrections de maquette :** https://github.com/dragnoir/knr-maison-celestine/blob/main/docs/CORRECTIONS-MAQUETTE.md

Les incohérences de prix et de contenu entre les deux maquettes ont été harmonisées sur la référence desktop et documentées. Le code est livré en un seul commit. Le dépôt réunit le code spécifique et l’assembleur ; la licence Horizon est conservée et le thème complet est installé sur la boutique.

Je suis disponible pour vous présenter l’architecture, l’édition des contenus et les choix d’intégration.

Bonne journée,  
Rachid
