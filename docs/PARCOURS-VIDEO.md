Le hero reste non cliquable, sans symbole plus. La galerie mobile défile ; le zoom est réservé aux deux images secondaires desktop. Les formulaires montrent une validation réelle : la vidéo n’annonce aucune nouvelle inscription ni nouvelle réception d’e-mail. Les succès serveur historiques sont documentés séparément.

Les seize séquences ont un journal de capture sans erreur d’action ; les seize images de milieu de chapitre et les métadonnées du fichier ont été inspectées. Les variations de contenu, le focus clavier visible et le badge antispam natif de Shopify restent présents dans l’interface enregistrée.

Aucun score de performance n’est affiché dans la vidéo. Les résultats gardent leur date dans le rapport, dont la nouvelle passe du 26 octobre ; Safari/iOS reste non vérifié.
